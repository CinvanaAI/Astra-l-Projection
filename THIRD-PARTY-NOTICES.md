# Dependencies and distribution

The MIT license covers this package's implementation and documentation. Unreal Engine is a separately installed dependency governed by Epic's terms; no engine source, engine binaries, marketplace content, character assets, textures, animations or maps are distributed here. References to engine-provided diagnostic primitives resolve against the recipient's own engine installation.

Python is a separately installed dependency. The Python utilities use the standard library. An AI host is optional for the diagnostic path. The optional Codex adapter requires the recipient's own Codex CLI installation and authentication; Codex and model access are not included in this package.

The package contains no model weights, account credentials, private conversation, original avatar, or original room. Importing your own assets or using another provider does not change the licenses applicable to those separate dependencies.

Official references: [Epic plugin documentation](https://dev.epicgames.com/documentation/unreal-engine/plugins-in-unreal-engine), [Codex non-interactive mode](https://learn.chatgpt.com/docs/non-interactive-mode).
