# Changelog

## 0.1.0-preview.1 — 2026-09-13

First public developer preview of Astra-l-Projection.

- Source-only AgentEmbodiment Unreal plugin with observation, movement, looking, stopping and text exchange.
- Portable Python command client and subprocess conversation bridge.
- Deterministic diagnostic provider and optional Codex CLI adapter.
- Installation, extension, reviewer and contribution guides; source inventory and test records.
- Automated Python checks on Windows and Linux. Native Unreal validation is documented separately.

The native source is the same implementation validated in the original 0.1.0 starter checkpoint. Repository presentation and packaging have been added for public review. This is an experimental source release; live Codex inference and arbitrary user-avatar integration are not certified by the existing tests.
